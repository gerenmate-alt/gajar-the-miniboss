# 🍄 Super Big Head Bros. — 2D Mario Platformer

Klasszikus 2D-s Super Mario stílusú böngészős platformer játék **Big Head** főszereplésével!

## 🎮 Irányítás (Billentyűzet & Mobil Érintőképernyő)

| Billentyű | Művelet |
| :--- | :--- |
| `A` / `D` vagy `◀` / `▶` | Mozgás balra / jobbra |
| `SPACE` / `W` / `▲` | Ugrás *(nyomva tartva magasabbra ugrik)* |
| `SHIFT` / `X` / `F` | Sprint + **👍 Lájkgolyó lövés** *(Lájk Király módban)* |
| `P` / `ESC` | Szünet |
| `M` | Retro Chiptune zene és hangeffektek némítása |
| 📱 gomb | Képernyőn lévő mobil irányítógombok be-/kikapcsolása |

---

## ⭐ Játékmenet & Képességek
- **🍄 Mega Big Head Gomba:** Növeli a fejed méretét, így egy találatot túlélsz és alulról szét tudod fejelni a téglablokkokat.
- **😎 Lájk Király (Virág Power-up):** Arany nyakkendőt és napszemüveget kapsz, és a `SHIFT` / `X` gombbal pattogó **👍 Lájkgolyókat** lőhetsz az ellenfelekre.
- **⭐ VIP Csillag:** Ideiglenes szivárványos sebezhetetlenség.
- **3 világ:**
  1. **1-1: Big Head Királyság** *(Napsütéses pálya)*
  2. **1-2: Éjszakai Neon Alagút** *(Mozgó liftek és cső-növények)*
  3. **1-3: VIP Kastély & BOSS** *(Láva és a **Mega Hater Király** főellenség)*
